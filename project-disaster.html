Project Overview

This project presents an AI-powered, IoT-integrated early warning system designed to detect environmental triggers and predict geo-hazard events — primarily landslides — before they cause casualties. The system combines real-time sensor networks with GPS tracking and Python-based machine learning models to issue timely alerts.

Showcased at the GMRT Science Day Exhibition, Narayangaon, Maharashtra (February 2025), this project demonstrated the practical deployment of geospatial AI in disaster risk reduction workflows.

Methodology

The system architecture integrates three core layers: a physical sensor network (IoT devices measuring soil moisture, temperature, precipitation, and wind speed), a geospatial layer (GPS-enabled location tracking of field sensors), and an AI/ML prediction layer built in Python.

Sensor data is streamed in real-time to a processing pipeline where engineered features are passed to trained classification models. Alert thresholds are dynamically updated based on seasonal baselines and historical hazard records.

1

IoT Sensor Deployment

Field sensors measuring soil moisture, temperature, precipitation intensity, and wind speed installed at high-risk slope locations identified via DEM analysis.

2

Real-Time Data Ingestion

GPS-tagged sensor readings streamed continuously to central processing server. Data validated, cleaned, and timestamped for ML pipeline input.

3

Feature Engineering & ML Prediction

Python-based ML models (Random Forest, Gradient Boosting) trained on historical hazard records and multi-parameter environmental data to classify hazard probability levels.

4

Alert Generation & Visualization

When probability exceeds defined thresholds, the system triggers automated alerts. Hazard zones visualized on GIS dashboards for emergency response coordination.

Key Outcomes

The system was successfully demonstrated at the GMRT Science Day Exhibition 2025. The multi-hazard adaptability of the architecture means the same sensor-ML pipeline can be reconfigured for flood monitoring, cyclone tracking, and extreme heat events by adjusting input parameters and retrained model weights.

The project establishes a replicable framework for community-level disaster preparedness in geologically vulnerable regions of India, particularly the Western Ghats and Himalayan foothills.
